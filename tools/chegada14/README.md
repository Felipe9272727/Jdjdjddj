# Chegada a Kessar-9

The 12-second opening is an edited first-person montage of five original Blender/Cycles plates. The camera drop, impact, breath, wind and light transitions are composed in Remotion. It is **not** a full-frame 3D character animation: there is no placeholder character, and camera movement within each shot uses the rendered plate. The cut to the helmet is an editorial insert; the last shot returns to the player's landing position.

- `cena.py`: procedural terrain, oak/brass portal and diving helmet, physically lit materials. Its terrain function matches `jubileu/src/f14Terreno.ts`; game `(x,y,z)` maps to Blender `(x,z,y)`.
- `denoise.py`: official Intel OIDN RT on sRGB plates; original renders are preserved. Download the Linux CLI from https://github.com/RenderKit/oidn/releases (tested with 2.5.1).
- `audio.py`: seeded original wind, portal, sand impact, breath and heartbeat. No third-party audio or generative voice.
- `composition.jsx` / `render.mjs`: isolated Remotion entry point; exports the H.264/AAC game asset and six review frames.
- `../carregamento-video/src/Chegada14.jsx`: cut timings, camera effects and title typography.

## Rebuild

Requires Blender 4.3+, Python with NumPy/Pillow and Intel Open Image Denoise CLI, Node 20+, Chromium and ffmpeg. Debian's Blender build has no OpenImageDenoise; the scene deliberately uses 32 samples with denoising disabled. CPU render time depends on the host (about 1–2 minutes per plate on the development machine).

```sh
npm ci --prefix tools/carregamento-video --no-audit --no-fund
blender -b -t 3 -P tools/chegada14/cena.py -- tools/chegada14/frames all
OIDN_BIN=/path/to/oidnDenoise python tools/chegada14/denoise.py
python tools/chegada14/audio.py
node tools/chegada14/render.mjs
```

Use `CHROMIUM_PATH` to override `/usr/bin/chromium`. `PLATE_SCALE=50` renders half-resolution previews. A single plate can be regenerated by replacing `all` with `portal`, `vista`, `fall`, `helmet` or `ground`.

Generated PNGs, WAV and `.blend` live in ignored `frames/`. The shipped result is `jubileu/public/chegada-14.mp4` (1280×608, 24 fps, 12 seconds). The optional old Manim source remains for archival purposes; Manim is not a dependency of this edit.
